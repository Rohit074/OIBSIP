# 🌐 NextGen AI - Landing Page

## 📌 Project Overview

NextGen AI is a modern, responsive landing page developed as part of the **Oasis Infobyte Web Development Internship (Level 1 - Task 1)**.

The website showcases an AI startup with a clean user interface, responsive design, and multiple sections including Hero, Features, About, Testimonials, Contact, and Footer.

---

## 🚀 Technologies Used

- HTML5
- CSS3

---

## ✨ Features

- ✅ Sticky Navigation Bar
- ✅ Hero Section with Call-to-Action Button
- ✅ Features Section
- ✅ About Us Section
- ✅ Testimonials Section
- ✅ Contact Section
- ✅ Footer with Social Links
- ✅ Smooth Scrolling Navigation
- ✅ Responsive Design (Mobile Friendly)
- ✅ Hover Effects and Modern UI
