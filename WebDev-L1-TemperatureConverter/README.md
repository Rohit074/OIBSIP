# 🌡️ Temperature Converter Website

## 📌 Project Overview

The **Temperature Converter Website** is a responsive web application developed as part of the **Oasis Infobyte Web Development & Designing Internship (Level 1 - Task 3)**.

This application allows users to convert temperatures between **Celsius**, **Fahrenheit**, and **Kelvin** with proper input validation and a clean, user-friendly interface.

## 📖 Temperature Conversion Formula

### Celsius to Fahrenheit

```
°F = (°C × 9/5) + 32
```

### Fahrenheit to Celsius

```
°C = (°F − 32) × 5/9
```

### Celsius to Kelvin

```
K = °C + 273.15
```

### Kelvin to Celsius

```
°C = K − 273.15
```

---

## 🌍 Absolute Zero Validation

The application prevents invalid temperature values below absolute zero.

| Unit | Minimum Value |
|------|---------------:|
| Celsius | -273.15 °C |
| Fahrenheit | -459.67 °F |
| Kelvin | 0 K |
